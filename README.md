# High Guard Shipyard Port Workspace

## Overview

This repository now contains two tracks:

1. `archive/original-lazarus/` - Archived Lazarus/Delphi source for High Guard Shipyard 2.x.
2. `web/` - New single-page web application port (Vue 3 + Vite + TypeScript).

The original source code in this repository was provided by Nicole Susans.

## Attribution

- Original desktop application: High Guard Shipyard v2.x.
- Original author: Andrea Vallance.
- Source in this repository provided by Nicole Susans.

## Local development (web app)

```bash
cd web
npm install
npm run dev
```

To build locally:

```bash
cd web
npm run build
```
