# Agent Instructions

- AI agents may assist with this repository, but must not be added as contributors or collaborators.
- Do not add AI or agent names, email addresses, or `Co-Authored-By` trailers to commit messages.
- Do not use an AI or agent identity as the Git author or committer. Commits must use the human maintainer's configured identity.
- Do not grant, retain, or request repository collaborator access for an AI agent or AI service.
- A human maintainer must review and approve changes before committing or pushing them.
