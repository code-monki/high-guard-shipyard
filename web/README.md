# High Guard Shipyard Web Port

Prototype single-page web port of the original High Guard Shipyard desktop application.

## Scripts

- `npm run dev` - Run local dev server.
- `npm run build` - Type-check and create production bundle.
- `npm run preview` - Preview production bundle.

## Optional GitHub Pages base path

Set `VITE_BASE_PATH` when building for a project site:

```bash
VITE_BASE_PATH=/high-guard-shipyard/ npm run build
```
